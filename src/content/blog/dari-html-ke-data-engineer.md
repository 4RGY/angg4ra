Repo pertama saya di GitHub adalah website artikel statis. HTML murni, CSS inline di beberapa tempat, JavaScript hanya untuk tombol navbar. Malu? Sedikit. Tetapi itu titik awalnya.

## Lini Masa yang Berantakan

Awal 2024: HTML, CSS, membuat website statis untuk tugas kuliah. Setiap website baru berarti menyalin templat lama lalu mengganti isinya.

Pertengahan 2024: Mengenal PHP. Membuat sistem informasi untuk desa, vihara, bahkan ERP untuk toko kacamata. Semuanya memakai PHP native. Tidak ada framework. Tidak ada version control yang benar. Push langsung ke production.

Akhir 2024: Mulai mengajar di DigiKidz. Ini belokan yang tidak saya duga. Mengajarkan anak-anak coding justru membuat saya sadar berapa banyak fundamental yang saya lewati.

2025: Python menjadi segalanya. Pandas, Scikit-learn, analisis data, ML. Berpindah dari "membuat website" ke "membuat sesuatu dari data".

2026: Astro untuk portfolio, FastAPI untuk backend, Docker untuk deployment, dan sekarang mempelajari AI agent untuk otomasi.

## Yang Tidak Lurus

Kalau dilihat dari luar, jalurnya tampak rapi: web, backend, data, ML, AI. Kenyataannya berantakan.

Saya pernah tertahan 3 minggu pada satu bug PHP yang ternyata hanya titik koma yang hilang. Pernah mengumpulkan proyek kuliah yang berjalan di laptop saya tetapi gagal di laptop dosen. Pernah membuat model ML dengan akurasi 99 persen dan saya bangga sekali, sampai sadar model itu hanya menghafal data latih.

Setiap kenaikan tingkat selalu dimulai dari kegagalan yang memalukan.

## Efek DigiKidz

Mengajar anak-anak adalah pengubah permainan yang tidak saya perkirakan.

Ketika harus menjelaskan loop kepada anak 8 tahun, Anda dipaksa benar-benar memahami loop. Bukan sekadar sintaksnya, melainkan konsepnya. Mengapa ia ada. Kapan dipakai, kapan tidak perlu. Analogi apa yang paling pas.

Anak-anak juga jujur. Mereka tidak berpura-pura mengerti. Kalau penjelasan Anda buruk, mereka langsung terlihat bosan atau bingung. Tidak ada basa-basi "oh iya, paham kok".

Itu umpan balik tercepat yang pernah saya dapat.

## Sekarang dan Nanti

Target saya: Data atau AI Engineer. Bukan karena istilahnya terdengar keren, melainkan karena saya menemukan bahwa menggali cerita dari data itu benar-benar menyenangkan.

Tetapi saya tidak mau meninggalkan web. Sebab data tanpa antarmuka hanyalah spreadsheet. Dan spreadsheet tidak bisa mengubah keputusan orang kalau tidak disajikan dengan benar.

Jadi posisi ideal saya: orang yang bisa mengambil data mentah, membersihkan, menganalisis, lalu menyajikan hasilnya lewat sesuatu yang bisa dipakai orang. Ujung ke ujung.

Dari HTML statis ke pipeline data. Tidak lurus, tidak sempurna, tetapi setidaknya saya terus berjalan.
